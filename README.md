# Прогнозирование ROA предприятий Казахстана

Материалы исследовательской практики и экспериментальной части магистерской диссертации Габиденова Арсена Муратовича, Astana IT University.

**Тема:** «Разработка интеллектуальной системы анализа и прогнозирования финансово-экономических показателей предприятий».

Репозиторий содержит исходные для моделирования таблицы компаний, отдельные макроэкономические ряды, код, прогнозы, метрики и отчёт. Материалы организованы по темам десятинедельного календарного плана. Это отражение фактически выполненных исследований; задания учебных дисциплин и эксперименты на Kaggle сюда не включены.

## Что получено

Годовой архив: **196 строк, 15 компаний**, неравномерное покрытие 2006–2025. Основная сопоставимая выборка — 165 строк 14 компаний; после построения лагов — 151 строка. Основной тест — 88 наблюдений за 2018–2024. У простого прогноза MAE **4.424 п.п.**, у исходного GB без макропризнаков — **4.515 п.п.** Последующий GB с MAE дал **4.201 п.п.**, но этот вариант исследован после просмотра исходного теста.

Квартальный пилот: **72 строки, 3 компании**, 2020Q1–2025Q4; тест — 24 наблюдения за 2024–2025. В основном сценарии с предполагаемой задержкой в два квартала MAE сезонного простого прогноза **0.653 п.п.**, GB MAE без макропризнаков — **0.505 п.п.**, CatBoost MAE с макропризнаками — **0.596 п.п.** Это ограниченный ретроспективный пилот; годовые и квартальные ошибки напрямую не сравниваются.

## Быстрый запуск

Нужен Python 3.12. Проверенное окружение исходного исследования — 3.12.14; версии библиотек зафиксированы в `requirements.txt`.

```bash
python -m venv .venv
```

Активируйте окружение: в Windows PowerShell `.venv/Scripts/Activate.ps1`, в Linux/macOS — `source .venv/bin/activate`. Затем из корня:

```bash
python -m pip install -r requirements.txt
python code/verify_manifest.py
python code/check_dataset.py
python reproduce.py
python code/analyze_results.py
python reproduce_bootstrap.py
```

Для повторного обучения с сохранёнными параметрами:

```bash
python reproduce.py --fit
```

Для полного повторения выбора параметров исходного годового пилота:

```bash
python reproduce.py --nested
```

Выходы повторных расчётов сохраняются в `recomputed/`. Для вычислений по включённым CSV интернет и PDF не нужны; установка библиотек может требовать интернет. [Обзорный блокнот](notebooks/01_data_and_results.ipynb) показывает данные и результаты, а обучение запускает только при явном переключении флага.

## Границы выполненной работы

Даты реальной доступности всех отчётов не восстановлены, используются в том числе ретроспективные версии. Дополнительные эксперименты выполнены после анализа ошибок; нет заявления о нетронутом финальном тесте. LSTM/GRU, SHAP и интервальные прогнозы пока не реализованы. Выполненная сверка данных не заменяет независимый финансовый аудит. [Подробности](docs/REPRODUCIBILITY.md).
