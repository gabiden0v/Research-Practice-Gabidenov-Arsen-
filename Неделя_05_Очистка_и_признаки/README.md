# Очистка и признаки

[Словарь годовых полей](../data/annual/data_dictionary.json) фиксирует смысл показателей. [Исторический код подготовки](../code/original/harmonize_dataset_20261016.py) содержит правила отбора, маскировку несопоставимых темпов роста и построение лагов.

ROA = общая чистая прибыль после налога / активы на конец периода. Значение хранится как доля; ошибки в таблицах моделей — в процентных пунктах. Это не ROA по средним активам и не нормализованная операционная рентабельность.

Из основной годовой выборки исключены 19 строк Тенгизшевройла из-за иной базы отчётности, 11 строк Озенмунайгаза с неопределённым охватом/неполным периодом и отдельная отчётность Мангистаумунайгаза за 2025 год. Причины сохранены в `exclusion_reason`.

Признаки строятся по точному прошлому году; пропущенный год не подменяется предыдущей строкой. Числовые пропуски в признаках обрабатываются внутри каждого обучающего разбиения. В исходной отчётности пропуски остаются пропусками. Отметки о разрывах целевого периода не используются как предикторы.

Квартальная прибыль получается разностью накопленных значений; Q4 = год − 9 месяцев. Остатки активов не суммируются. Прямо раскрытая квартальная прибыль проверяется отдельным сценарием. Полная историческая база дат публикации не восстановлена.

Проверка структуры и арифметики: `python code/check_dataset.py` из корня репозитория. Она не заменяет сверку каждой цифры с PDF. Полная разметка ОКЭД и набор денежных потоков пока не подготовлены.
