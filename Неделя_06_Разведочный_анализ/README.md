# Разведочный анализ

Таблицы формируются командой `python code/analyze_results.py` из корня:

- [Покрытие годовых данных](../results/diagnostics/annual_coverage.csv).
- [Пропуски годовых показателей](../results/diagnostics/annual_missingness.csv).
- [Распределение ROA по компаниям](../results/diagnostics/annual_roa_summary.csv).
- [Покрытие квартальных данных](../results/diagnostics/quarterly_coverage.csv).

Это описательные сводки сохранённых данных, заново сформированные при упаковке материалов 16.11.2026. Они не являются новым экспериментом обучения. Полный корреляционный анализ по секторам остаётся отдельной задачей; денежные показатели разных валют нельзя складывать.
