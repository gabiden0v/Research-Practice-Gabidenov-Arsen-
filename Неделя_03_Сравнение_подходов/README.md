# Сравнение подходов

| Подход | Что проверяет | Реализация в пилоте |
|---|---|---|
| Перенос последнего ROA | Инерционность показателя | Годовой и квартальный ориентиры |
| Сезонный простой прогноз | Повторение того же квартала прошлого года | Квартальный ориентир |
| Ridge | Регуляризованная линейная зависимость | Годовая панель |
| Random Forest | Нелинейный ансамбль деревьев | Годовая панель |
| Gradient Boosting | Последовательное обучение деревьев | Годовая и квартальная панели |
| CatBoost | Бустинг с разными потерями и составом признаков | Годовая и квартальная панели |
| Pooled LSTM/GRU | Общие последовательности компаний | В плане; результатов нет |

Используется совместное обучение по нескольким компаниям. Идентификаторы компаний и сектор включены в годовые модели как категориальные признаки. Это не причинная оценка отраслевого эффекта и не доказательство переноса на новую компанию.

Обучение и настройка идут по времени. Годовые внешние тестовые годы — 2018–2024; настройки выбираются по более ранним внутренним разбиениям. Для квартального пилота используются фиксированные компактные настройки и тест 2024Q1–2025Q4.

Подробности: [годовой протокол](../results/annual/model_protocol.json), [квартальный протокол](../results/quarterly/protocol.json). Полноценное сравнение моделей отдельно по секторам требует расширения покрытия.
