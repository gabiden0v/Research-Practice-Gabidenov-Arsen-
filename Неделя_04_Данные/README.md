# Данные

| Набор | Файл | Объём |
|---|---|---|
| Годовые показатели компаний | [company_financials.csv](../data/annual/company_financials.csv) | 196 строк, 15 компаний, неравномерное покрытие 2006–2025 |
| Годовые внешние показатели | [macro_by_year.csv](../data/annual/macro_by_year.csv) | Отдельные ряды по годам |
| Квартальные показатели компаний | [company_quarterly.csv](../data/quarterly/company_quarterly.csv) | 72 строки, Kcell, KEGOC и КазТрансОйл, 2020Q1–2025Q4 |
| Квартальные внешние показатели | [macro_quarterly.csv](../data/quarterly/macro_quarterly.csv) | Отдельные ряды по кварталам |

Годовая основная выборка содержит 165 исходных строк 14 компаний и 151 строку с допустимыми лагами. 196 архивных строк не равны числу обучающих наблюдений. Данные компаний и внешние ряды хранятся отдельно и объединяются через прошлый период, доступный по предположениям протокола.

[Описание единиц и источников](../data/README.md), [годовой реестр](../data/annual/source_registry.json), [квартальный реестр](../data/quarterly/source_registry.json), [таблица известных URL](../data/annual/source_url_crosswalk.json).

Воспроизведение вычислений начинается с извлечённых таблиц. Исходные PDF в репозиторий не включены. В календарном плане упомянут DFO, но массовая загрузка и полное покрытие этого портала не заявляются выполненными.
