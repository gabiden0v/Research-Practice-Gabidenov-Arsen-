Файлы `original/` сохранены побайтово. Их исторические `main()` используют рабочие архивные пути и не предназначены для отдельного запуска из этого репозитория. Переносимые точки входа находятся в корне: [reproduce.py](../reproduce.py), [reproduce_bootstrap.py](../reproduce_bootstrap.py). Они вызывают функции исторических модулей на включённых CSV; алгоритмы не изменены.

Полное извлечение из исходных PDF с нуля этим пакетом не воспроизводится. В историческом квартальном модуле при импорте может создаваться пустая служебная папка `code/original/outputs/`; она исключена из Git.
