# Обзор литературы

[32 библиографические записи](references.md) перенесены из расширенного отчёта без изменения. Полный связный обзор находится в разделе 1 отчёта, а не в отдельных копиях чужих статей. Доступность внешних ссылок при сборке этого репозитория повторно не проверялась.

| Тема | Источники в списке | Связь с исследованием |
|---|---|---|
| Прогнозирование финансовых показателей | 1–6 | Различие между объяснением зависимости и качеством прогноза |
| Базовые методы и объединение прогнозов | 7–10 | Простой прогноз как обязательный ориентир |
| Регуляризация и ансамбли деревьев | 11–17 | Выбор семей моделей для табличной панели |
| Нейросети и обучение групп рядов | 18–21 | Возможное продолжение; нейросетевой эксперимент не выполнен |
| Внешние факторы и финансовая отчётность | 22–24 | Состав признаков, промежуточные периоды и частота данных |
| Проверка качества и переобучение | 25–28 | Временные разбиения и ограничение повторного выбора по тесту |
| Неопределённость и интерпретация | 29–32 | Будущие интервальные прогнозы и объяснение признаков |

Наличие метода в литературе не означает его реализацию в пилоте. Конформные интервалы, SHAP, LSTM и GRU здесь не представлены как полученные результаты.
