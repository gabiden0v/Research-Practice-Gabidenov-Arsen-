# Сохранённые результаты

- `annual/`: исходный годовой пилот и четыре сценария, временные разбиения, параметры, прогнозы и метрики. Основной сценарий — `main_ifrs`, тест 2018–2024. `exploratory_2025.csv` не является нетронутым контрольным тестом.
- `annual_extensions/`: последующие эксперименты с выбором простого прогноза, изменением ROA и функциями потерь. Идеи проверялись после просмотра исходных ошибок.
- `quarterly/`: три сценария квартального пилота; основной — `main_lag2`.
- `comparisons/`: дополнительные сравнения моделей с внешними признаками и без них.
- `diagnostics/`: описательные сводки и ошибки, пересчитанные скриптом `code/analyze_results.py` при упаковке.

Для всех таблиц `MAE_pp` и `RMSE_pp` означают процентные пункты ROA. Меньшее значение лучше. Интерпретировать их нужно вместе с частотой целевого показателя, составом компаний и тестовым периодом. 88 строк годового теста не равны 88 независимым макроэкономическим состояниям.

Новые повторные расчёты сохраняются в `recomputed/` в корне, чтобы исходные результаты оставались неизменными.
