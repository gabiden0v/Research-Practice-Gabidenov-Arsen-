# Организационный этап

Тема диссертации: «Разработка интеллектуальной системы анализа и прогнозирования финансово-экономических показателей предприятий».

Автор: Габиденов Арсен Муратович, Astana IT University, Applied Data Analytics.
Исследовательская практика: НИЦ «Cybertech», 07.09–14.11.2026.
Научный руководитель: Кисикова Нургуль Мырзабековна.
Руководитель базы практики: Рзаева Лейла Гумметовна.

Цель пилота — проверить прогноз ROA предприятий Казахстана на будущих относительно обучения периодах и оценить дополнительную полезность макроэкономической информации.

Исследовательские вопросы:

1. Превосходят ли обучаемые модели перенос последнего известного ROA?
2. Улучшают ли макропризнаки прогноз при одинаковых наблюдениях и временных разбиениях?
3. Меняют ли выводы функция потерь, прогноз изменения ROA и переход к квартальной частоте?

[Соответствие календарному плану](calendar_status.csv) отражает фактические результаты и незавершённые пункты. Папки сгруппированы по темам недель. Это структура материалов для отчётности, а не журнал фактических дат выполнения каждого эксперимента. Расчёты пилотов выполнены в октябре 2026 года; пакет оформлен 16 ноября.

Итоговый продукт этого этапа — данные, исследовательский код и результаты пилотов. Развёрнутая система поддержки решений пока не создана.
